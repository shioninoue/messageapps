# messageapps

# ① 課題名

LINE 風リアルタイムチャットアプリ

---

## ② 課題内容（どんな作品か）

- Firebase Realtime Database を使用したリアルタイムチャットアプリ
- 自分が送信したメッセージと相手が送信したメッセージを自動判別して表示（右寄せ／左寄せ）
- 自分の送信したメッセージのみ削除できる LINE 風 UI のチャット画面

---

## ③ アプリのデプロイ URL

https://shioninoue.github.io/messageapps/

---

## ④ アプリのログイン用 ID または Password（ある場合）

本アプリはログイン不要です。  
ブラウザごとに自動発行される UID により「自分／相手」を判別しています。

- ID: 不要
- PW: 不要

---

## ⑤ 工夫した点・こだわった点

- LINE のように **自分のメッセージは右側、相手のメッセージは左側** に表示される UI を再現
- 名前入力を省略し、ブラウザごとに生成する UID で送信者判定を実装
- Firebase の `onChildAdded` / `onChildRemoved` を使い、リアルタイムの送受信＋削除反映を実装
- 削除ボタンは **自分のメッセージにだけ** 表示されるように工夫
- 新しいメッセージが届くと自動的にスクロールが一番下に移動する UX を実装

---

## ⑥ 難しかった点・次回トライしたいこと（又は機能）

**難しかった点**

- 自分と相手を UID で区別するロジックの実装
- Firebase と DOM の削除処理をリアルタイムに同期させること
- LINE 風 UI（吹き出しや左右のレイアウト）の CSS 調整

**次回トライしたい機能**

- メッセージ編集機能（編集済み表示）
- 既読機能
- 個別ルーム・グループチャット化
- 画像送信機能
- Firebase Authentication を用いたログイン導入
